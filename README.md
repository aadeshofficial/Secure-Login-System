# Secure-Login-System

## Description
This project is a Secure Login System developed using Python, Flask, SQLite, and bcrypt. It provides a secure user authentication system with password hashing, session management, and database integration. The application allows users to register, log in securely, access protected pages, and log out while following secure authentication practices.

## Features
- User Registration
- Secure User Login
- Password Hashing with bcrypt
- Session Management
- SQLite Database Integration
- Protected Dashboard Access
- User Logout
- Simple and Responsive Interface

## Technology Used
- Python
- Flask
- SQLite
- bcrypt
- HTML
- CSS

## Installation

1. Clone the repository

```bash
git clone https://github.com/aadeshofficial/Secure-Login-System.git
```

2. Navigate to the project directory

```bash
cd Secure-Login-System
```

3. Install the required dependencies

```bash
pip install flask bcrypt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```
http://127.0.0.1:5000
```
